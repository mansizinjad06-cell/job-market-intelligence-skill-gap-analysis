Job Market Intelligence & Skill Gap Analysis System

1. Project Overview

The Job Market Intelligence & Skill Gap Analysis System is a data analytics project developed to study job market trends, salary patterns, skill requirements, job roles, industries, work modes, and candidate skill gaps.

The main purpose of this project is to understand how job market data can be stored, analyzed, and presented in a simple and useful way using SQL, Python, and an interactive dashboard.

For this project, a realistic synthetic dataset was created specifically for portfolio and educational analysis. The dataset is not collected from a live job portal or real company database. It was designed to represent realistic job-market scenarios while keeping the project suitable for learning and demonstration.

---

2. Problem Statement

Job seekers often have difficulty understanding which skills are in demand, what types of jobs are available, how salaries vary, and whether their current skills match job requirements.

The project aims to analyze these areas in a structured database and present the results through SQL analysis, Python visualizations, and a Streamlit dashboard.

---

3. Project Objectives

The main objectives of the project are:

- Store job market information in a structured MySQL database.
- Analyze job postings using SQL.
- Identify commonly demanded job roles and industries.
- Analyze minimum and maximum salary ranges.
- Identify the most demanded technical skills.
- Analyze remote, hybrid, and onsite opportunities.
- Compare job skill demand with candidate skills.
- Perform additional analysis using Python and Pandas.
- Create visualizations using Matplotlib.
- Build an interactive dashboard using Streamlit.
- Present useful insights in a simple and understandable format.

---

4. Key Project Highlights

Database & SQL

- Designed a relational MySQL database for job market analysis.
- Created separate tables for companies, industries, job roles, job postings, skills, candidates, and related entities.
- Used primary keys and foreign-key relationships.
- Applied normalization principles to reduce unnecessary duplication.
- Performed Basic, Intermediate, and Advanced SQL analysis.
- Used joins, subqueries, aggregations, CTEs, CASE statements, and window functions.

Skill Analysis

- Identified the most demanded skills.
- Compared market demand with candidate skill availability.
- Calculated skill gaps.
- Performed candidate skill matching against job requirements.

Python Analysis

- Connected Python directly with MySQL.
- Loaded database data using Pandas.
- Performed grouping and aggregation.
- Analyzed salary, work mode, job type, experience, and skill demand.
- Created basic charts using Matplotlib.

Dashboard

- Built an interactive Streamlit dashboard.
- Connected the dashboard directly to MySQL.
- Added job market overview metrics.
- Added skill demand and salary analysis.
- Added work mode and skill gap analysis.
- Displayed job posting data in an interactive table.

---

The project uses a synthetic but realistic job market dataset.

The dataset was created for:
